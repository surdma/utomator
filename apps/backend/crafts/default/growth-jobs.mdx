## Step: evidence | Verify job requirements
<a id="step-evidence" />

**Evidence and research:**
- Match actual qualifications and identify missing skills
- Align resume, portfolio and LinkedIn profile for a specific vacancy

Distinguish verifiable sources, user-provided context and unknown claims.

**Next:** [develop](#step-develop)

## Step: develop | Align factual career evidence
<a id="step-develop" />

**Specific deliverables:**
- Prepare applications, cover letters and interview evidence
- Track saved, applied, interviewing, rejected, offer and accepted states

The graph designs an evidence-backed result; it does not claim external API execution.

**Next:** [approval](#step-approval)

<a id="step-approval" />

Require account-owner approval and exact provider permission before external changes.

**Next:** [outcome](#step-outcome)

## Step: outcome | Assess opportunity outcomes
<a id="step-outcome" />

Complete only the evidence-backed review and owner decision.

**Available today:** Existing resume workspace supports career documents; there is no integrated job search or application tracker.
