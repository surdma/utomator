# Application tailoring

## Step: scope | Read actual job requirements
<a id="step-scope" />
<CraftNode kind="brief" x={80} y={130} />

Use a specific role advert, requirements and the employer's stated context.

**Next:** [evidence](#step-evidence)

## Step: evidence | Match confirmed achievements
<a id="step-evidence" />
<CraftNode kind="research" x={390} y={130} />

Map documented achievements, projects and measurable results to role requirements, preserving attribution.

**Next:** [develop](#step-develop)

## Step: develop | Tailor the resume
<a id="step-develop" />
<CraftNode kind="draft" x={700} y={130} />

Reorder and rewrite existing evidence to show useful outcomes and problem solving for that employer.

**Next:** [approval](#step-approval)

## Step: approval | Prepare supporting materials
<a id="step-approval" />
<CraftNode kind="review" x={1010} y={130} />

Draft an employer-specific cover note, references and interview examples supported by the same verified facts.

**Next:** [outcome](#step-outcome)

## Step: outcome | Review for truthful submission
<a id="step-outcome" />
<CraftNode kind="measure" x={1320} y={130} />

Check dates, claims, links, formatting and candidate approval; never claim the application was submitted automatically.

**Next:** End
