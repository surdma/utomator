# Portfolio proofing

## Step: scope | Define proof target
<a id="step-scope" />
<CraftNode kind="brief" x={80} y={130} />

Identify the role, partner or reviewer and competencies the portfolio piece must demonstrate.

**Next:** [evidence](#step-evidence)

## Step: evidence | Verify project contribution
<a id="step-evidence" />
<CraftNode kind="research" x={390} y={130} />

Verify authentic links, dates, outcomes, permissions and personal contributions rather than attributing team results to the owner.

**Next:** [develop](#step-develop)

## Step: develop | Prepare a case study
<a id="step-develop" />
<CraftNode kind="draft" x={700} y={130} />

Describe the real challenge, work performed, decisions taken and observable results. Flag absent proof.

**Next:** [approval](#step-approval)

## Step: approval | Place supporting material
<a id="step-approval" />
<CraftNode kind="review" x={1010} y={130} />

Draft Featured descriptions, portfolio captions, source references and useful verification links.

**Next:** [outcome](#step-outcome)

## Step: outcome | Validate portfolio credibility
<a id="step-outcome" />
<CraftNode kind="measure" x={1320} y={130} />

Review confidentiality, accuracy, link destinations and owner approval; measure qualified interest when evidenced.

**Next:** End
